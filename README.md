# Sales Data Analysis & Interactive Dashboard

This project focuses on analysing sales data and transforming raw, unorganized data into meaningful business insights using Microsoft Excel, Power Query, and Power Pivot.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Power Query
- Power Pivot
- Pivot Tables & Pivot Charts
- Data Visualization

## 🔄 Project Workflow

### 1. Data Cleaning & Preparation – Power Query
The raw sales data contained several issues that needed to be cleaned and prepared before analysis.

Key tasks included:
- Removing duplicate records.
- Handling missing values.
- Identifying and correcting negative or invalid quantities and prices.
- Managing cancelled orders.
- Standardizing data formats and column values.
- Transforming and preparing the data for analysis.

### 2. Data Modeling – Power Pivot
After cleaning the data, Power Pivot was used to build a structured data model.

- Created relationships between the main tables.
- Connected sales data with related tables such as Products, Customers, and Regions.
- Built a model that allows data from multiple tables to be analysed together.

### 3. Data Analysis – Pivot Tables
Pivot Tables were created to analyse the main sales metrics and performance.

The analysis included:
- Total Revenue
- Total Profit
- Units Sold
- Average Order Value (AOV)
- Sales by Region
- Sales by Category
- Top Customers
- Top Products
- Sales performance over time
- Year and Quarter comparisons

### 4. Dashboard Creation
An interactive sales dashboard was created to present the results clearly and support quick decision-making.

The dashboard includes:
- KPI Cards
- Interactive Charts
- Pivot Charts
- Slicers
- Revenue and Profit analysis
- Sales performance analysis
- Year and Quarter filters

## 📊 Key Insights
The dashboard helps identify:
- Overall sales and profit performance.
- High-performing regions and categories.
- Top customers and products.
- Changes in sales performance over time.
- Important trends and patterns in the sales data.

## 🎯 Project Goal
The main goal of this project was to demonstrate how raw sales data can be cleaned, transformed, modelled, analysed, and visualized to generate clear and useful business insights.
